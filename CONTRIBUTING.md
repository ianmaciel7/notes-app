# Contributing

- [ ] Use `pnpm install` to install dependencies.
- [ ] [ ] Use `pnpm dev` to run local development server.
- [ ] Follow OpenSpec for behavioral/procedural changes: proposal, specs, design, tasks.
- [ ] Keep language in repository-facing docs and code in English.
- [ ] Submit PRs with change name and summary.

## Branching

- Create changes on dedicated branches.
- Prefer small incremental PRs.
