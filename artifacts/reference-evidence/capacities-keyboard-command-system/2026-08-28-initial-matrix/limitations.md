# Limitations

- This bundle is an initial implementation matrix built from reusable sanitized evidence. It does not claim live parity for global palette shortcuts or the new object/block triggers.
- `Mod+K`, `Mod+P`, selected-text `Mod+K`, `@`, `[[`, and `((` require matched reference/localhost browser acceptance after implementation.
- Authenticated reference mutation paths remain prohibited unless an interaction is explicitly reversible and safe.
- No cookies, tokens, credentials, storage values, private content, raw authenticated HTML, or complete third-party exports are stored.
