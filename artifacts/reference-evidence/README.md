# Reference Evidence Bundles

Store reusable external UI evidence under `<source-id>/<capture-id>/` and include a `manifest.json` based on `manifest.example.json`. Read `docs/references/reference-evidence-workflow.md` before adding or refreshing a bundle.

Existing files in `artifacts/capacities-reference/` remain valid legacy evidence; migrate them only when a future comparison refreshes the same state.
