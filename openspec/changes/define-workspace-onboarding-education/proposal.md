## Why

An object-centric workspace fails if users keep thinking in files and folders. The product needs educational onboarding that teaches the methodology of thinking in connected objects before and during use.

## What Changes

- Add an onboarding methodology module for object-first thinking.
- Add guided first-run flows that help users create object types, objects, relationships, collections, and daily notes.
- Add contextual education that explains why an object, relation, backlink, graph, or collection matters at the moment of use.
- Add progress and dismissal behavior so onboarding helps without blocking expert users.

## Impact

- Planning only; no runtime code changes in this change.
- Depends conceptually on workspace navigation, object model, collections, relations, and visual experience.
