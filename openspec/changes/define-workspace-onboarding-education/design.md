## Context

The workspace is positioned as a "Studio for the Mind", not a generic notes editor. Onboarding must teach the mental model: ideas are objects with type, metadata, relationships, collections, and graph context.

## Decisions

### Teach methodology before mechanics

The first-run experience should explain the object mindset before asking users to organize content. The goal is to prevent users from recreating folder hierarchies.

### Use progressive education

Guidance appears in first-run setup, empty states, tooltips, checklists, and contextual panels. Users can skip, resume, and revisit lessons.

### Measure understanding through actions

Completion is based on meaningful actions: creating a type, creating an object, editing metadata, linking objects, opening backlinks/graph, and creating a collection view.

## Risks / Trade-offs

- Too much onboarding can block advanced users.
- Too little onboarding makes the object model feel arbitrary.
- Educational copy must avoid implying direct parity with any competitor brand.
