## Why

Collections, saved views, search, in-page find, calendar, and daily notes are related discovery and retrieval surfaces. They should be implemented as one focused feature group rather than mixed with graph, AI, or editor internals.

## What Changes

- Define object-type collection pages and saved views.
- Define contextual creation from collections.
- Define global Ctrl+K action/content palette and extended search.
- Define in-page find.
- Define calendar and daily notes.

## Impact

- Planning only; no runtime code changes in this change.
- Depends conceptually on the knowledge object model and workspace navigation.
