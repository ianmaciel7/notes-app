## Why

The product needs built-in self-service support and a feedback/community loop. Help should not be limited to static links; users should understand UI commands, report issues, suggest improvements, and find authoritative in-app reference material.

## What Changes

- Add an internal knowledge base for FAQ, UI reference, shortcuts, object methodology, and advanced features.
- Add a community/feedback loop for suggestions, bugs, and status of submitted reports.
- Add support links and safe telemetry payloads from the UI.
- Add triage metadata and privacy constraints for feedback submissions.

## Impact

- Planning only; no runtime code changes in this change.
- Depends conceptually on settings, navigation, observability, and onboarding.
