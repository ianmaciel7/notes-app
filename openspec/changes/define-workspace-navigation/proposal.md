## Why

Workspace navigation should be implemented independently from domain modeling and editor behavior. The shell, sidebar, tabs, contextual panels, focus mode, and responsive navigation define how users move through the product.

## What Changes

- Define persistent object-centric workspace shell behavior.
- Define tabs and contextual right-side panels.
- Define visual placement for space selector, object-centric sidebar sections, compact tabs, and sliding contextual panels.
- Define focus mode and responsive navigation behavior.

## Impact

- Planning only; no runtime code changes in this change.
- Depends conceptually on workspace foundation and visual experience for shared UI rules.
