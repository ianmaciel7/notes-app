## Why

Relations, backlinks, semantic discovery, and graph interaction are the core of the connected-object experience. They should be specified separately from search, editor, and AI provider behavior.

## What Changes

- Define typed relationships and backlinks.
- Define context panels for internal objects, incoming links, and related content.
- Define semantic discovery surfaces.
- Define interactive graph behavior.

## Impact

- Planning only; no runtime code changes in this change.
- Depends conceptually on the knowledge object model, navigation, and visual experience.
