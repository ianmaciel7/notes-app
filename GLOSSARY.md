# Notes Application

A personal knowledge management system designed for capturing, organizing, and retrieving thoughts and multimedia content.

## Language

**Note**:
Atomic unit of recorded thoughts, text, or media.
_Avoid_: memo, document, item, file

**Notebook**:
Organized container grouping cohesive notes.
_Avoid_: folder, directory, collection, category

**Tag**:
Non-hierarchical label attached to notes for cross-cutting categorization.
_Avoid_: label, keyword, metadata, mark

**Draft**:
An uncommitted or work-in-progress note state prior to explicit saving or publishing.
_Avoid_: unsaved note, scratch, buffer

**Revision**:
An immutable historical snapshot of a note's state at a distinct point in time.
_Avoid_: version, checkpoint, backup, undo state

**Workspace**:
The top-level isolated domain environment encapsulating all user notebooks, notes, and preferences.
_Avoid_: account, space, project, tenant

**Excerpt**:
Short, extracted textual preview of a note displayed in lists and navigation views.
_Avoid_: snippet, summary, preview text
