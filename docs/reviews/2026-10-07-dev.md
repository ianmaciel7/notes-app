## Standards review

1. **Fixed — logout fail-closed behavior:** The previous
   `SignOutButton` ignored errors from `DELETE /api/auth/session`, so it
   could sign out only the browser SDK while the HttpOnly server session
   remained active. The replacement verifies successful server logout first,
   reports an error to the user, and prevents repeat submission while pending.
   Regression tests cover an unsuccessful response, network failure, and
   successful server-to-client logout ordering.
2. **Fixed — stale current-state documentation:** The README, Architecture,
   Testing, Security, Tooling, and authentication/Firestore ADRs previously
   described implemented authentication or locale foundations as absent,
   presented the unit suite as smoke-only, or listed the Firebase directory
   as nonexistent. They now distinguish implemented features from planned
   exam-domain, Firestore data, and locale preference work.
3. **Fixed — stale plan and relative links:** A draft written after the
   authentication implementation was incorrectly under active plans.
   It is archived as superseded with a dated note, with relative paths
   repaired. A check of selected Markdown references found no outstanding
   broken links after the repair.
