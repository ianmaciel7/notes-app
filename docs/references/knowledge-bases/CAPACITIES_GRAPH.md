Space, Object, Object Type, Property, Block, Tag, Collection, Query, Daily
Note, Task, Template, Image, Weblink, PDF, File, API Structure, API Token,

## Features

Object Types, Properties, Block Editor, Tags, Collections, Queries, Search and
Command Palette, Daily Notes, Knowledge Graph, Templates, Task Management,
Task Actions, AI Assistant, AI Chat Connectors, Offline-First Work,
Synchronization, Media Management, Media Analysis, Import, Bulk Import,
Exports and Backups, Keyboard Shortcuts, Mobile, Tablet, REST API, MCP, and
Two-Factor Authentication.

## Workflows

Create an object; create a custom object type; build a network of notes; create
and reuse a query; create a recurring task; bulk import content; schedule a
full export; prepare a device for offline work; enable two-factor
authentication; use a personal API token; connect an MCP-capable client; and
configure a Readwise import.

## Graph Interpretation

Capacities models knowledge as connected objects with configurable types,
properties, blocks, tags, collections, and queries. This supports the generic
object foundation, but vendor-specific behavior remains reference material.
