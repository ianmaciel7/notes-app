# Visual Design & Reference Invariant

- NEVER copy third-party website raw colors, styles, or aesthetics verbatim (e.g. ExamTopics raw blue headers or exact clone styling). Third-party images are functional references only (e.g. demonstrating the need to display questions, options, solution reveal).
- ALWAYS adhere strictly to `DESIGN.md` and project semantic design tokens (`bg-card`, `bg-primary`, `border-border`, `text-foreground`, etc.) using shadcn/ui `base-nova` style with Base UI primitives and Tailwind CSS.
- Ensure all components support both light and dark mode automatically through semantic tokens.
