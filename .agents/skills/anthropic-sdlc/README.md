# AI-Native SDLC Skill

A reusable Agent Skill derived from Anthropic's official AI-native SDLC Playbook.

## Contents

- `SKILL.md` — workflow and trigger instructions
- `assets/intent-template.md` — intent proto-spec template
- `assets/spec-template.md` — requirements/design spec template
- `assets/plan-template.md` — implementation plan template
- `references/official-anthropic-sources.md` — official source map

## Suggested project installation

Copy this directory to:

`.claude/skills/anthropic-sdlc/`

The skill is deliberately self-contained and avoids third-party process conventions unless your repository adds them separately.
