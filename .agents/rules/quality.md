# Quality Gate

Follow the repository policy in `AGENTS.md` and `docs/code-quality.md`.

Run relevant checks after meaningful code, config, lockfile, or test changes. Run `pnpm verify` before declaring an implementation complete. Never invent results, weaken gates, lower thresholds, update baselines, or hide failures to claim success.
