# Rule: Code and Documentation Language Standard

## Description
Enforce English as the primary and mandatory language for all source code, documentation, configuration files, rules, and commit messages across the repository.

## Mandatory Guidelines

1. **Rule Files and Agent Configurations**:
   - All agent rules (`.agents/rules/*.md`) and instructions (`AGENTS.md`, `CLAUDE.md`) must be written in English.

2. **Source Code & Comments**:
   - Variable names, function names, class names, code comments, docstrings, and type definitions must strictly be in English.

3. **Documentation & Commit Messages**:
   - All repository documentation (`README.md`, architectural specs, markdown guides) and git commit messages must be written in English.

4. **Consistency Enforcement**:
   - Agents must write all code, configuration files, rules, and persisted repository artifacts in English regardless of the user's conversational prompt language.
