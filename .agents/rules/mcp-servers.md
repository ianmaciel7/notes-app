# MCP Server Requirements & Usage Rules

## Recommended MCP Servers

### 1. Open Design MCP (`open-design`)
- **Purpose**: Used for visual design system extraction, UI component synchronization, and asset management.
- **Trigger**: Activate when designing UI screens, implementing design tokens, or inspecting visual mockups.
- **Setup**: Configured locally per developer machine. Template provided at [.agents/mcp_config.example.json](file:///C:/Users/ianma/workspace/notes-app/.agents/mcp_config.example.json).
- **Fallback**: If the Open Design MCP tools are unavailable, remind the user to start the Open Design desktop application and verify their local `mcp_config.json`.
