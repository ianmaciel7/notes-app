## Repository Rules

- This project follows OpenSpec for behavioral/process changes.
- Documentation and workflow updates are governed by:
  - .agents/rules/openspec-first.md
  - .agents/rules/english-first.md
  - docs/practical-workflow (OpenSpec capability under openspec/specs/docs/practical-workflow/spec.md).

## Practical documentation synchronization

For process-facing or workflow-related doc updates, keep README, .agents guidance, and practical docs in the same change.
README.md, .agents rules, and openspec/specs/* should not diverge after a change is merged.
